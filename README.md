# Meu Primeiro Projeto Web

## Sobre o projeto

Projeto desenvolvido para praticar meus conhecimentos em desenvolvimento web durante minha formação em **Análise e Desenvolvimento de Sistemas**.

Criei uma página de apresentação pessoal utilizando HTML, CSS e JavaScript, aplicando conceitos de estruturação, estilização, responsividade e interação com o usuário.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- Git/GitHub

## Funcionalidades

- Página de apresentação pessoal
- Layout responsivo
- Links de contato
- Interações com JavaScript
- Criação dinâmica de cards de habilidades
